# Good Practices for Software Development

## Which point(s) were new to you?

* Making notes during requirement discussions is very important.
* Sharing written requirements with the team helps avoid confusion later.
* Over-communicating with the team is considered a good practice.
* Informing the team immediately about delays or technical issues is necessary.
* Asking questions properly with clear explanations helps get faster answers.
* Joining meetings early can help build better relationships with teammates.
* Blocking distractions like social media during work hours can improve focus and productivity.
